# Demo media and attribution

Bike Buddy keeps its demonstration media under `backend/uploads` and stores
portable paths such as `/uploads/bike/demo/pulsar-220f-1.jpg` in MongoDB. The
web portal and Flutter app resolve those paths against their configured API
origin, so the same seed works on Windows, an Android emulator, and a deployed
demo backend.

The motorcycle photographs below were downloaded from Wikimedia Commons as
1280-pixel thumbnails on 5 August 2026. Bike Buddy renamed the files and
resized copies are served locally; no endorsement by the photographers or
Wikimedia is implied. Each local copy remains available under the source
license shown here. Exact trims or model years are not inferred from a photo
when the source page identifies only the broader motorcycle family.

## Synthetic fixtures

- `uploads/profile/demo-*.png` contains generated initials, not photographs of
  real people.
- `uploads/kyc/demo-*-id.png` is stamped **NOT A REAL IDENTITY DOCUMENT** and
  exists only to demonstrate the protected KYC review flow.
- `uploads/evidence/demo-*.png` is stamped **DEMO ONLY – NOT PHOTOGRAPHIC
  EVIDENCE** and exists only to demonstrate support, checklist, and damage
  evidence interfaces.

Runtime Multer uploads remain ignored by Git. Only the explicit `demo` media
patterns in `backend/.gitignore` are versioned, and runtime cleanup refuses to
delete these fixtures.
